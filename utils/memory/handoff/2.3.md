# Task 2.3 & 2.4 Handoff: AES-128-CTR Dual-Port BRAM Accelerator & Testbench

## 1. Summary of Completed Work
- **RTL Implementation**: Authored `cora7z/app/hw/src/aes_accel.vhdl` implementing 128-bit iterative AES-CTR (NIST FIPS-197 and NIST SP 800-38A compliant, 10 rounds, SubBytes, ShiftRows, MixColumns, AddRoundKey, big-endian 128-bit counter increment).
- **Dual-Port BRAM Architecture**: Connected to native synchronous Port B BRAM bus (`bram_in_*` and `bram_out_*`) per ADR-012/ADR-017, supporting direct 32-bit word streaming.
- **CSR Interface**: AXI4-Lite slave mapped at `0x43C10000` with 32-bit hardware cycle counter, key registers (`0x14-0x20`), IV registers (`0x24-0x2C`), and initial counter (`0x30`).
- **Verification**: Authored `cora7z/app/hw/test/tb_aes_accel.vhdl`. All 3 VUnit test cases passed (CSR, NIST SP 800-38A golden vector match over BRAM, soft reset).

## 2. Invariants for Subsequent Tasks
- Address map for AES Input BRAM: `0x40010000` - `0x40011FFF` (8 KB).
- Address map for AES Output BRAM: `0x40012000` - `0x40013FFF` (8 KB).
- Accelerator control register at `0x43C10000`.
- Software driver configures KEY/IV, writes payload length to `0x08`, pulses bit 0 of `0x00` (START), and polls `0x04` for DONE.

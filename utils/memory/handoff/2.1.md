# Task 2.1 & 2.2 Handoff: LZSS Dual-Port BRAM Accelerator & Testbench

## 1. Summary of Completed Work
- **RTL Implementation**: Authored `cora7z/app/hw/src/lzss_accel.vhdl` implementing a sliding-window dictionary compressor (Heatshrink-compatible, 256 B window, 16 B lookahead, 3 B min match, 8-token flag chunking).
- **Dual-Port BRAM Architecture**: Connected to native synchronous Port B BRAM bus (`bram_in_*` and `bram_out_*`) per ADR-012/ADR-017, preventing LUT multiplexer explosion.
- **CSR Interface**: AXI4-Lite slave mapped at `0x43C00000` with 32-bit hardware cycle counter.
- **Verification**: Authored `cora7z/app/hw/test/tb_lzss_accel.vhdl`. All 3 VUnit test cases passed (CSR, compression ratio verification, soft reset).

## 2. Invariants for Subsequent Tasks
- Address map for LZSS Input BRAM: `0x40000000` - `0x40001FFF` (8 KB).
- Address map for LZSS Output BRAM: `0x40002000` - `0x40003FFF` (8 KB).
- Accelerator control register at `0x43C00000`.
- Software driver must write uncompressed length to `0x08`, pulse bit 0 of `0x00` (START), and poll `0x04` for DONE.
